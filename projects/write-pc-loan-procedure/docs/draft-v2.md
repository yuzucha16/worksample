# PC 貸し出し表の管理 手順書（初稿 v2・レビュー用）

状態: **AI の初稿。未承認**。v1 のレビュー回答（2026-10-07）を反映し、「機械の番号の調べ方」を足した。`【】` は未記入、`※` はレビューで決めたい点。A4 1〜2枚に収める。

## 0. この手順書でやること

会社の PC 5台を貸し出すとき、「いつ・誰に・どの PC を貸したか」を1つの表に残し、なくなったらすぐ気付けるようにします。

- 貸し出し表の置き場: 共有フォルダA の表計算ファイル（1つだけ。コピーは作らない）
- 困ったとき・紛失のとき: コンプライアンス管理部【電話番号】

## 1. 貸し出し表

書くのは次の列です。

| 列 | 内容 |
|---|---|
| PC の番号 | 1〜5 |
| 機械の番号（MAC アドレス） | 最初に1回だけ控える（下の「準備」） |
| 借りた人 | 氏名 |
| 貸した日 | 年月日 |
| 返す予定の日 | 貸した日から**最長1週間後**まで |
| 上司の承認 | 承認メールの日付 |
| 返した日 | 返却時に書く |
| 状態 | 貸出中 / 貸出可 |

準備（最初の1回だけ）: 5台の機械の番号を調べ、表に書き写す。調べ方は、下の「機械の番号の調べ方」を見る。

### 機械の番号（MAC アドレス）の調べ方

機械の番号は、PC 1台ごとに決まっている、英数字12文字の番号です（例: `A1-B2-C3-D4-E5-F6`）。

**方法1（まず試す）**: ITサービス台帳で、その PC の行を探して、番号を書き写す。

**方法2（台帳に番号がないとき）**: その PC を起動して、次の順に開く（Windows の場合）。

1. 画面左下の「スタート」を押し、「設定」を開く。
2. 「ネットワークとインターネット」を押す。
3. 「Wi-Fi」を押す（有線で使う PC は「イーサネット」）。
4. 「ハードウェアのプロパティ」を押す。
5. 「物理アドレス (MAC)」の右に出ている番号を、そのまま表に書き写す。

注意:
- 書き写したら、もう一度見比べる（1文字違うと、番号が役に立たない）。
- 【Wi-Fi と有線のどちらの番号を控えるか】※決めたい（両方の番号を控える場合は、表に列を足す）。

## 2. 貸すとき

1. 借りたい人から、依頼を受ける。
2. 借りたい人に、上司の承認メールを、事務員を「写し（Cc）」に入れて送ってもらう。そのメールは、【メールの保存先フォルダ名】に残す。承認メールがなければ貸さない。
3. 空いている PC を選び、表の「状態」が「貸出可」であることを確かめる。
4. 表に、借りた人・貸した日・返す予定の日（最長1週間後）・承認メールの日付を書き、状態を「貸出中」にする。
5. PC を渡す。

## 3. 返してもらうとき

1. PC を受け取り、表の「返した日」を書く。
2. 次の人に貸せる状態にする: 個人のデータを消す。目で見て汚れがない程度に拭く。※「個人のデータを消す」の具体的なやり方（【やり方】）。
3. 状態を「貸出可」にする。

## 4. 週に1回の確認（毎週【曜日】）

1. 表を見て、「貸出中」の人と PC を一覧にする。
2. 返す予定の日が、**来週までに来る人と、過ぎている人**に、「PC はいま手元にありますか」とメールで聞く。
3. 過ぎている人には、返却を頼む。
4. 返事がない人、または「手元にない」という返事は、次の「なくなったとき」へ進む。

## 5. なくなったとき（すぐに）

見つけた時点で、次の3つをすぐに行います。

1. 上司と事務員に、電話か口頭で伝える（夜間・休日も、同じやり方）。
2. 表の該当の行に、気付いた日時と状況を書く。
3. コンプライアンス管理部のホットラインに電話する【電話番号】。

詳しい対応: 【既存の取り決めの場所】
